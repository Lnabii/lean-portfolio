# Lean Naive — Portfolio

Portfolio of Lean Naive, a 20-year-old BSCS 3B student and web & mobile developer from Poblacion, Candijay, Bohol. Projects, awards and numbers are mock content for a class project.

**Stack:** Next.js 15 (static export) · React 19 · Tailwind CSS 4 · Framer Motion

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static site in ./out
```

Content lives in `app/data.ts`. Pushing to `main` deploys to GitHub Pages through `.github/workflows/deploy.yml` (set **Settings → Pages → Source** to **GitHub Actions**).
